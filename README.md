# 🌸 GIGA句会プラザ 〜こころを詠む〜

**クラス全員で俳句を詠み、読み合い、投票して、結果を発表するまでを1つの画面で行う Web アプリです。**

Google アカウントさえあれば、サーバー代も外部サービスの契約もなしに動きます。
データの保存先は、先生自身の Google ドライブに自動で作られるスプレッドシート1つだけです。

国語の俳句づくりはもちろん、理科の実験後や体育の試合後などの「振り返り」を
五・七・五で書く使い方もできます。

> **操作の詳細・句会の進め方・つまずいたときの対処は [MANUAL.md](./MANUAL.md) にまとめています。**
> 表示とアクセシビリティの実測結果は [AUDIT.md](./AUDIT.md) にあります。

## 📱 何ができるか

画面は5つで、下記のタブで切り替えます（画面遷移のない React の SPA です）。

| タブ | 誰が使うか | できること |
|---|---|---|
| **投稿** | 児童 | 名前と五・七・五を入力して投稿。入力中は右側に短冊のプレビューが出る |
| **広場** | 児童 | 全員の作品を短冊の一覧で読む。1句ずつ開いて投票・コメント |
| **自分** | 児童 | 自分が過去に詠んだ全作品と、もらったコメントを振り返る |
| **過去** | 児童 | 終わった句会の作品を、開催日ごとに読み返す |
| **先生** | 先生 | パスワードで入り、お題・投票状態・作品の表示/非表示を管理 |

### 👧 児童向け

* **短冊プレビュー** — 入力した文字がその場で縦書きの短冊に反映されます。
  （画面幅 768px 以上のときだけ表示されます。スマートフォンの縦持ちでは出ません）
* **文字数の目安表示** — 各行の下に「現在 ○ 文字 (目安:5)」と出ます。
  **目安を超えても投稿できます。** 字余り・字足らずを止める仕組みではありません。
* **投票（金・銀・銅）** — 1人が使えるのは **金1回・銀1回・銅1回** です。
  同じ作品に2回は投票できません。自分の作品には投票・コメントの欄が出ません。
* **コメント** — 1句につき何件でも書けます。投票を締め切ると書けなくなります。
* **紙吹雪** — 投票が成功したときと、結果発表の画面を開いたときに舞います。
* **並び替え** — 広場の作品を「新しい順」「ランダム」で並び替えられます。
* **再読み込みボタン** — 画面を更新せずに最新の作品を読み込めます。
  **自動では更新されません。** 新しい作品を見るにはこのボタンを押します。
* **ルビ（ふりがな）** — 各タブの名前と、各画面の見出し・投稿ボタンに付いています。
* **キーボードだけでも使えます** — Tab で短冊に移動し、Enter で開けます。
  モーダルは Esc で閉じ、閉じると元の短冊に戻ります。
* **画面の幅に合わせて字が大きくなります** — スマホでははみ出さず、大きな画面では大きく。

### 👨‍🏫 先生向け（管理ダッシュボード）

* **参加状況の数値表示** — 参加児童数・総投稿数・総投票数・コメント数を、
  数字と横棒のゲージで表示します。**自動更新はしません**。「↻ 最新の情報に更新」を押します。
* **お題の変更** — テキスト欄を書き換えて「お題を更新」。
* **投票の受付／締切の切り替え** — ワンタップで切り替わります。
  **締め切った瞬間に、広場が結果発表の画面に変わり、作者名が公開されます。**
* **ワンタップ・ミュート** — 不適切な作品の「👁️ 隠す」を押すと、広場から消えます。
  データは削除されません。「非表示中 (戻す)」でいつでも戻せます。
* **新しい句会の準備** — 現在の作品・コメント・投票を日時つきのシートに退避し、
  空のシートを作り直します。退避した分は児童の「過去」タブから読めます。
* **提示モード（電子黒板）** — 広場の「🖥 大きく表示」で、字も余白も1.5倍になり全画面になります。
  **提示中は受賞者の名前を既定で伏せます**（`〇〇〇`）。「名前を出す」で明かせます。
* **印刷** — 締切後の広場に「🖨 印刷」があります。A4縦で、ナビ・ボタン・紙吹雪は刷りません。
* **パスワードの設定・変更** — **初期パスワードはありません。**
  いちばん最初に「先生」タブを開いた人が、その場で決めます（6文字以上）。
  決めたあとは管理画面の下部でいつでも変えられます。
  合言葉は平文では持たず、SHA-256 のハッシュにして保存します。

> 🔒 **管理操作はサーバー側で確認しています。** 以前は `updateSettings` /
> `toggleMuteHaiku` / `resetKukai` / `getAdminDashboardData` が合言葉を見ておらず、
> 児童が開発者ツールから直接呼べました。いまはログイン時に受け取った合鍵を
> サーバー側で照合します。**先生用タブを離れると合鍵は消えるので、入り直しが必要です。**

### まだ無いもの

正直に書きます。以下は**実装されていません**。

* **CSV などのファイル書き出し** — 結果を成績処理用にダウンロードする機能はありません。
  データは自動生成されたスプレッドシートにそのまま入っているので、
  当面はそれを直接開いてコピーするか、Google スプレッドシートの
  「ファイル > ダウンロード」をお使いください。
* **自動更新（リアルタイム更新）** — 児童の広場も先生のダッシュボードも、
  ボタンを押したときにだけ読み直します。
* **折れ線・円などのグラフ** — ダッシュボードにあるのは数字と横棒のゲージです。
* **PWA / オフライン対応** — GAS は画面を iframe で包むため、このままでは PWA にできません。
  GitHub Pages 側にシェルを置く構成に変える必要があります（[AUDIT.md](./AUDIT.md)）。
* **CSP（コンテンツセキュリティポリシー）** — GAS の `HtmlService` が独自の
  サンドボックスで包むため、本番で確かめないと入れる判断ができません。

## 🚀 導入手順

事前の準備は Google アカウントだけです。

> ⚠️ **貼り付けるファイルは5つあります。**
> `app-shell.html` は残りの3つ（`app` / `css` / `vendor`）を読み込む造りなので、
> **1つでも欠けると画面が真っ白になります。** 名前も下表のとおり正確に付けてください。
>
> **以前の版では、この外枠の名前は `index` でした。** すでに `index` で貼って
> お使いの学級は、そのままで動きます（`code.gs` が `app-shell` を先に探し、
> 無ければ `index` に落ちます）。貼り直すときに `app-shell` へ変えてください。

### 1. プロジェクトを作る

[https://script.new/](https://script.new/) を開き、もとから入っているコードをすべて消して、
このリポジトリの **`code.gs`** の中身を貼り付けます。

### 2. HTML ファイルを4つ足す

左の「ファイル」横の「＋」＞「HTML」を選び、**4回**繰り返します。
GAS は拡張子を自動で付けるので、**名前は拡張子なしで入力**してください。

| GAS で付ける名前 | 貼り付ける中身 | 大きさ |
|---|---|---:|
| `app-shell` | `app-shell.html` | 1 KB |
| `app`   | `app.html`   | 66 KB |
| `css`   | `css.html`   | 32 KB |
| `vendor`| `vendor.html`| 157 KB |

> 大きさは 2026-08-22 の実測（合わせて 256 KB）。`app` と `css` は、
> 以前ここに書いてあった 52 KB / 28 KB から増えています。

`vendor` は React 本体などが入っているため長いですが、
**全文を選択してそのまま貼り付けてください**（途中で切れると画面が出ません）。

### 3. デプロイ（公開）する

1. 右上の「デプロイ」＞「新しいデプロイ」
2. 左上の歯車マークから「ウェブアプリ」を選択
3. 設定：
   * 実行するユーザー: **自分**
   * アクセスできるユーザー: **同一ドメインの全員**（＝学校の Google アカウントを持つ人だけ。こちらを推奨します）

   > ⚠️ **「全員（匿名ユーザーを含む）」を選ぶと、URL を知っていれば誰でも投稿・投票・コメントができます。**
   > 児童が URL を外に貼れば校外の人も書き込めますし、投票の重複を防いでいるのは
   > 端末ごとの識別子だけなので、荒らしを止める手立てが実質ありません。
   > 端末が学校アカウントでログインしていない等の事情でやむを得ず選ぶ場合は、
   > 句会の期間だけ公開し、終わったらデプロイを停止してください。
4. 表示された URL を児童に共有すれば準備完了です。

> **💡 初回アクセス時に起きること**
> 最初に URL が開かれた瞬間、スプレッドシート **「【自動生成】GIGA句会プラザ_DB」** が
> **デプロイした人（先生）の Google ドライブ**に自動で作られます。
> 事前にスプレッドシートを用意したり ID を設定したりする必要はありません。
> **管理ページに初期パスワードはありません。** 最初に「先生」タブを開いたときに
> 設定画面が出るので、そこで決めてください（6文字以上）。
> **この設定画面が出ているあいだは誰でも決められるので、児童に URL を配る前に
> 先生が先に開いて決めてください。**

導入後の進め方は [MANUAL.md](./MANUAL.md) をご覧ください。

## 🛠 技術スタック

**CDN は使っていません。** 学校のフィルタリングで CDN が塞がれると画面が一切出なくなるため、
ライブラリはすべてビルド時に取り込み、GAS 側に置いています
（経緯と実測値は [AUDIT.md](./AUDIT.md) にあります）。

| 役割 | 使っているもの | 配り方 |
|---|---|---|
| バックエンド | Google Apps Script | `code.gs` |
| データベース | Google スプレッドシート | 初回アクセス時に自動生成 |
| 画面 | React 18.3.1 / ReactDOM 18.3.1 | `vendor.html` に同梱 |
| スタイル | Tailwind CSS 3.4.19 | 使用クラスのみ抽出して `css.html` に同梱 |
| アニメーション | canvas-confetti 1.6.0 | `vendor.html` に同梱 |
| JSX の変換 | @babel/preset-react | **ビルド時のみ**。ブラウザには送りません |
| アイコン | インライン SVG | `src/app.jsx` に直接記述 |

唯一の外部読み込みは和風フォント（Google Fonts の Yuji Syuku）ですが、
**届かなくても端末側の明朝体に落ちるだけで、表示は崩れません。**

## 👩‍💻 開発者向け

```bash
npm ci                              # 版は package-lock.json で固定
npm run build                       # app.html / css.html / vendor.html を作り直す
npm run check                       # 下の検査を、CI と同じ順で全部まわす
```

| ファイル | 中身 | 編集してよいか |
|---|---|---|
| `src/app.jsx` | 画面本体（JSX） | **ここを直す** |
| `code.gs` | サーバー側の処理 | ここを直す |
| `app-shell.html` | アプリの外枠。`include()` で3つを読む | ここを直す |
| `index.html` | サイトのトップに出す導入案内。GAS には送らない | ここを直す |
| `tools/extra.css` | Tailwind に無い追加のスタイル | ここを直す |
| `tailwind.config.js` | Tailwind の設定 | ここを直す |
| `app.html` / `css.html` / `vendor.html` | 生成物 | **手で編集しない** |

> ⚠️ **`src/app.jsx` を直したら、必ず `npm run build` を走らせてから push してください。**
> 生成物を更新し忘れると、変更が画面に出ません。
> **CI がこれを見張っています**（生成物と原本がずれていると PR で落ちます）。

`google.script.run` が無い環境（GAS の外）で開くと、`src/app.jsx` の `runGas` が
ダミーデータを返すので、ブラウザだけでも画面の見た目を確認できます。

### 検査

| コマンド | 何を見るか |
|---|---|
| `npm run check` | 下の全部を、CI と同じ順でまわす |
| `npm run check:built` | 生成物が原本と一致しているか（`npm run build` の忘れ） |
| `npm run check:gate` | CDN依存・拡大禁止・`100vh`・ふりがなの色・管理者APIの認可など13項目 |
| `npm run check:self-test` | **検査そのものを、わざと壊して落ちることを確かめる** |
| `npm run check:admin` | 合鍵なしで管理者APIが弾かれるか |
| `npm run check:cell` | 児童の書いた文字が、表計算のなかで数式として動き出さないか |
| `npm run check:shell` | 外枠（`app-shell`）の読み分け。前の版を貼ったままの学級でも画面が出るか |

> **`npm run check` という名前は変えないでください。** `main` にマージしたときに走る
> Deploy（`.github/workflows/deploy.yml`）は、`package.json` の
> `quality` / `ci` / `check` を順に探して**見つかった1つだけ**を実行します。
> どれも無いと「飛ばします」と表示して、**検査を1つも通さないまま本番の
> Apps Script へ push します**（この3つが無い状態が、実際にそうなっていました）。

`--self-test` があるのは、「0件でした」だけでは検査が動いているのか
何も見ていないのか区別できないためです。実際、この仕組みを作る過程で
判定器の不具合が2件見つかりました（[AUDIT.md](./AUDIT.md)）。

**静的な検査だけでは足りません。** コントラスト・タップ領域・キーボード操作は
実ブラウザで測る必要があります。測り方は [AUDIT.md](./AUDIT.md) にあります。

### `appsscript.json` について

`timeZone` / `runtimeVersion` を明示するために置いています。

- **コピペで導入する場合は貼り付け不要です。** GAS のエディタでは既定で隠れており、
  「プロジェクトの設定」＞「`appsscript.json` マニフェスト ファイルをエディタで表示する」を
  有効にしないと見えません。clasp を使う場合に効きます。
- **`oauthScopes` はあえて書いていません。** このアプリは `SpreadsheetApp.create()` で
  ドライブにファイルを作るため必要なスコープの粒度が粗く、**外して間違えると
  全教員で認可が通らなくなり授業が止まります。** 本番で確かめられないうちは
  GAS の自動推定に任せるのが安全です。
