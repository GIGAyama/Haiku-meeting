そのまま貼れる形で書いてあります。画像は `images/` にあります。

## 1. 貼るまえに直すところ

| 箇所 | いまの状態 | やること |
|---|---|---|
| タイトル1行目の `#◯` | 伏せてある | 連載の番号に置きかえる。前回が #9（Qalc）だったので、そこから数える |

番号は推測で埋めていません。間違えると連載が壊れるためです。**ここだけは手で直してください。**

タイトル行の残り（「書いて出して、終わり」にしない。〜）は、そのまま使える想定です。
別案として「短冊を集めて貼る時間を、読み合う時間に。クラス全員の句会アプリ「GIGA句会プラザ」」も
検討しましたが、困りごとが前に出る前者を採りました。

## 2. note への貼りかた

1. note の新規記事を開き、1行目の `# 教室で使えるかもしれないもの作り #◯ …` をタイトル欄に入れる。
   `#` は取り除く。
2. 残りの本文を、そのまま本文欄に貼る。`##` の見出しはそのまま貼れば見出しになる。
   note は見出しから目次を自動で作るので、順番は変えないほうがよい。
3. 画像は自動で入らないので、`images/` から手でアップロードする。
   本文の `![…](images/xx.png)` の行が入る位置。貼ったら Markdown の行は消す。
4. 画像の下に置いてある一文は、note の**キャプション欄**に移す。本文に残すと二重に見える。
5. ハッシュタグは `#GIGAスクール` `#小学校` `#国語` `#俳句` `#教育ICT` `#GoogleAppsScript` あたり。

太字・表・記号（→ ／ ： ▲）は使っていません。note のエディタで崩れないことを優先しています。

## 5. 撮り直すときの手順

このアプリは Google Apps Script のうえで動くので、そのままではローカルのブラウザで
実データを触れません。撮影のときは、次の形で本物の画面を動かしました。

1. `npm i --no-save playwright` を入れる（`package.json` には残さない）。
2. `index.html` の `<?!= include('…') ?>` を、`vendor.html` `css.html` `app.html` の中身に
   置きかえた1枚の HTML を作る。画面（`app.html`）と処理（`code.gs`）はリポジトリのものをそのまま使う。
3. その HTML の中で、GAS のサービス（SpreadsheetApp / PropertiesService / CacheService /
   LockService / Utilities）を、その場かぎりの入れ物として用意する。
   `google.script.run` は `code.gs` の関数をそのまま呼ぶだけの橋にする。
   こうすると、置きかわるのは「スプレッドシート」だけで、画面と処理は本物のまま動く。
4. 表計算の中身として、20人が22句を出して読み合ったあとの状態を先に入れておく。
   投票は先に組み立て、得点はその合計から出す。画面に出る数字と食いちがわなくなる。
5. `scripts/serve.mjs`（note-article スキル）で配り、`scripts/capture.mjs` にシナリオを渡して撮る。
6. 撮り終わったら、作業用に置いたファイルを消し、`git status` と `git diff` で
   何も残っていないことを確かめる。

和風の書体（Yuji Syuku）は、撮影機から Google Fonts に直接届かなかったので、
同じフォントファイルを先に落として、同じ見た目で撮っています。

印刷の1枚だけは、ブラウザ自身の印刷用の描画に切りかえて撮っています。
`window.print()` を押すと OS の印刷ダイアログが開いて撮影が止まるためです。
出ている内容は、実際に紙へ載るものと同じです。

## 6. 文体について踏襲したこと

連載「教室で使えるかもしれないもの作り」の書きかたに合わせています。

- 太字・斜体・表を使わない。`→` `／` `：` `▲` のような記号も使わない
- Markdown は見出しだけ。箇条書きは手順のときだけ
- 専門用語を日常の言葉に置きかえる。「デプロイ」は「公開の設定」、
  端末に残る保存領域は「その端末に覚えられて」と言いかえた
- 絵文字は見出しだけ
- 子どものことは「子どもたち」、読み手は「先生」「先生方」
- 本文の字数は約 7,600 字（画像の行を除く）

見出しは基本の6本に、目玉として2本（🥇 と 🖥）を 📱 と ✨ のあいだに足しています。

### 書き足していただきたいところ

**教室での出来事は、実体験としては書いていません。** これは作者の実践記録ではないので、
「使ってみたら子どもたちが〜」と書くと嘘になります。書いてあるのは
「こうなればいいと思って作った」「〜だと思います」までです。

実際に授業でお使いになったあとで、そのときの子どもたちの様子を
「✨ 導入のメリット」か「📝 まとめ」に一段落足していただくと、記事の説得力が変わると思います。
