# スプレッドシートのコピーで配る（作者向けの手順）

このアプリは、作品を入れるスプレッドシートにスクリプトが束ねられた状態
（コンテナバインド）でも、独立スクリプトでも動きます。`code.gs` が
どちらかを見分けます（`getDbSpreadsheet()`）。

コピーで配ると、先生の手数が **5ファイル貼り付け → デプロイ** から
**コピー → デプロイ** に減ります。この文書は、そのテンプレートを作る手順です。

> **この作業は、Google アカウントを持つ人にしかできません。**
> リポジトリの側からは用意できないので、ここに手順だけ置いてあります。

---

## 1. テンプレートを作る

1. 新しいスプレッドシートを作り、名前を **「GIGA句会プラザ」** にする。
   （コピーすると「GIGA句会プラザ のコピー」になります。先生が名前を変えても構いません。）
2. シートは作らなくてよい。**最初に開かれたときに `ensureSheets_()` が
   「設定」「俳句」「コメント」「投票」を作ります。**
   先に作るなら、見出し行は `code.gs` の `SHEETS_` と同じにすること。
3. 「拡張機能」＞「Apps Script」を開く。
4. 既定の `コード.gs` の中身を消し、リポジトリの `code.gs` を貼り付ける。
   ファイル名は `コード` のままでよい（`.gs` の名前は動作に関係しません）。
5. 「＋」＞「HTML」で4つ作り、名前を **`app-shell` / `app` / `css` / `vendor`** にする。
   それぞれリポジトリの同名 `.html` の中身を貼り付ける。
6. いったん保存する。**デプロイはしない**（デプロイはコピーには付いてこないので、
   ここで作っても意味がありません）。

## 2. 中身を空にしておく

**テンプレートに残っているものは、コピーした全員に配られます。**

- 試しに投稿した句・名前・コメント・票を消す
- スクリプトのプロパティ（`ADMIN_PASSWORD_HASH` など）が入っていないか確認する
  （「プロジェクトの設定」＞「スクリプト プロパティ」）

> スクリプトのプロパティは**コピーされません**が、テンプレート側に残っていないことは
> 確かめておいてください。

## 3. 共有の設定

1. スプレッドシートの「共有」を開く。
2. 一般的なアクセスを **「リンクを知っている全員」＋「閲覧者」** にする。
   - **「編集者」にしないこと。** 編集者にすると、コピーせずに直接書き込めてしまいます。
3. リンクをコピーする。次の形になっているはずです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/edit?usp=sharing
   ```

4. 末尾を **`/copy`** に置きかえたものが、配るリンクです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/copy
   ```

   これを開くと「コピーを作成」のダイアログがすぐ出ます。

## 4. リンクを貼ってある場所（2026-08-23 に設定済み）

配っているリンクは1つです。

```
https://docs.google.com/spreadsheets/d/19VeKs838Yp8J4Xlxq4FWNfvmUj8u8ta31s2qOXGif0k/copy
```

| ファイル | 場所 |
|---|---|
| `README.md` | 「A. スプレッドシートをコピーする」の手順1 |
| `index.html` | サイトのトップの「入れかた」のボタン |
| `docs/note/*-note-article.md` | 紹介記事の「入れる手順」（giga-school.com が翌朝に組み直します） |

**テンプレートを作り直して ID が変わるときは、この3か所すべてを差し替えてください。**

## 5. 入れたあとに確かめること

手元では確かめられないので、実機で1回だけ見てください。

1. **別のアカウント**（できれば学校のアカウント）でコピーリンクを開き、
   コピーが作れるか。
   - **学校のドメインが「外部のファイルのコピー」を禁じていると、ここで止まります。**
     止まる場合は、手順 B（貼り付け）を案内し続けてください。
2. コピーしたファイルでデプロイし、URL を開いて画面が出るか。
3. 1句投稿し、**コピーしたそのファイル**の「俳句」シートに行が増えるか。
   （増えなければ `getActiveSpreadsheet()` が効いていません。
   その場合は「【自動生成】GIGA句会プラザ_DB」ができているはずなので、探してください。）
4. 「先生」タブを開き、合言葉の設定画面が出るか（テンプレートの合言葉が
   引き継がれていないことの確認になります）。
5. コピーしたファイルの上のメニューに **「GIGA句会プラザ」＞「シートを点検する」** が出るか。
   押して「シートの作りは想定どおりです」と出れば、見出しがそろっています。
   （このメニューは、スプレッドシートを開いたときに `onOpen` が作ります。
   独立スクリプトでは出ません。）

## 6. すでに配ってある学級について

**前の配り方（独立スクリプト）で公開済みの学級は、そのままで動きます。**
`getDbSpreadsheet()` は束ねられたファイルが無ければ、これまでどおり
`DB_SPREADSHEET_ID` の表計算ファイルを開きます。作品は消えません。

貼り直しをお願いするのは、`code.gs` の直し（数式の無害化など）を届けたいときだけです。
